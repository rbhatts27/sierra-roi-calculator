# Sierra ROI Calculator

A simple ROI calculator prototype for customer demonstrations.

## Quick Start

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the application:**
   ```bash
   python app.py
   ```

3. **Open in browser:**
   ```
   http://localhost:5000
   ```

## Features

- Calculate ROI based on cost savings projections
- Save data to Excel file (`roi_data.xlsx`)
- Search records by Customer Name or Account SID
- View all saved records

## Data Storage

All submissions are saved to `roi_data.xlsx` in the project root. The Excel file is created automatically on first submission.
